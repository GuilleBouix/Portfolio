Yagua Image Processor

Software open-source de procesamiento de imágenes

Aplicación de escritorio para procesamiento inteligente de imágenes, diseñada para comprimir, convertir, remover fondos, extraer paletas y optimizar recursos visuales desde una interfaz rápida y productiva.

Ver en GitHub

Características Principales

    Compresión inteligente con control de calidad

    Reducción de peso con ajuste preciso de calidad de salida.

    Conversión entre múltiples formatos

    Soporte para PNG, JPG, WebP, AVIF y más.

    Eliminación de fondo con IA

    Remoción precisa del fondo usando rembg offline.

    Redimensionado, recorte y edición en canvas

    Herramientas de edición integradas para ajuste visual.

    Extracción automática de paleta de colores

    Generación de paletas desde imágenes automáticamente.

    Renombrado masivo con vista previa

    Renombrado en lote con preview antes de aplicar.

    Gestión de metadatos EXIF

    Visualizar, editar y limpiar metadatos con piexif.

    Generación de LQIP y Base64

    Creación de placeholders optimizados para web.

    Soporte multi-idioma

    Disponible en español, inglés y portugués.

    Temas oscuros predefinidos

    Estética dark theme adaptada al sistema.

Tecnologías Utilizadas

Python CustomTkinter Pillow rembg piexif Pytest

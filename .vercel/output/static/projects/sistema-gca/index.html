Sistema GCA

Sistema de Gestión y Control de Asistencias

GCA es un sistema de control de asistencia de personal diseñado para gestionar los ingresos y egresos de empleados dentro de una empresa. El sistema registra los movimientos diarios para ofrecer información precisa sobre horas trabajadas, ausencias, tardanzas, justificaciones, horas extra y tiempo fuera del puesto laboral. La aplicación fue desarrollada como un sistema de escritorio utilizando C# .NET y Windows Forms, con foco en la confiabilidad y en un seguimiento preciso del tiempo para respaldar el control interno y la generación de reportes.

Ver en GitHub

Características Principales

    Login de Usuarios

    Acceso mediante usuarios con punto de entrada controlado.

    Registro de Asistencias

    Panel con ingresos/egresos, filtros, búsqueda y historial completo.

    Detección de Códigos por Teclado

    Listener que detecta códigos de 6 dígitos automáticamente.

    Gestión de Empleados

    Registrar, editar, eliminar y administrar empleados.

    Estadísticas y Reportes

    Métricas clave, gráficos y reportes por departamento.

    Configuración del Sistema

    Empresa, días laborales, horarios y puestos.

Tecnologías Utilizadas
